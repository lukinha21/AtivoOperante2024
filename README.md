# 🏗️ Ativo Operante 2024

Sistema desenvolvido com Java e Spring Boot para o controle e gestão de ativos operacionais de uma empresa.

## 🚀 Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Maven
- Thymeleaf
- PostgreSQL ou H2

## ⚙️ Como Executar

1. Clone o repositório:
   git clone https://github.com/lukinha21/AtivoOperante2024.git
   cd AtivoOperante2024
   
Compile e execute com Maven:
./mvnw spring-boot:run

Acesse a aplicação:
http://localhost:8080
